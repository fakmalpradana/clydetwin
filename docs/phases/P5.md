# Phase 5: "Immersive Glasgow" (brief)

**Goal.** `/immersive` v1 becomes a cinematic "Glasgow Now" view, with visual effects driven by real data. Release target is `v0.5.0`.

**What already exists.** The P1–P4 foundation is in place:
- renderer, atmosphere and sun shadows;
- our own terrain, LoD1 v3 / LoD2 pilot tiles, vehicles and river gauges;
- GPU fallback, plus camera sync with `/explore`.

P5 adds effects only. All work is web-side, in `web/`.

**Branches.**
- Phase branch `phase-5-immersive` comes off `phase-4-analytical-twin`.
- Single workstream `p5/immersive` in worktree `../clydetwin-web`.
- If a backend change is needed (e.g. a rain field in `/now`), stop and report; Opus will schedule it.

## Tasks

1. **Horizon artefact.** Fix the dashed line on the far horizon seen since P3. It exists with every vehicle removed, so it comes from the terrain, basemap overlay or atmosphere.
   - Find the cause first (systematic debugging) and record it in the commit body.
2. **Quality presets** `low | medium | high`.
   - Driven by detect-gpu tier, overridable with `?q=`.
   - Each preset controls DPR, shadow map size, clouds on/off and quality, and post-processing.
   - Show the active preset in a small HUD.
3. **Volumetric clouds** (`@takram/three-clouds`, version-locked, compatible with the installed `@takram/three-atmosphere` 0.19.1).
   - Coverage per layer comes from `/now.weather.cloud_low/mid/high` (fixture mode works).
   - Off in `low`.
4. **Rain.**
   - Precipitation intensity comes from `/now.weather.precip_mm`.
   - Use a lightweight GPU particle or screen-space rain, plus wet-look darkening.
   - No effect when there is no rain.
5. **Clyde water plane.**
   - A simple water surface along the River Clyde: OS Open Rivers or the OSM `natural=water` polygon. Verify the licence and attribute it.
   - Water height follows the nearest Clyde gauge value when available, otherwise a documented constant.
   - Use reflective or animated normals (an existing three/takram water or a minimal shader).
6. **Façade shader** (procedural).
   - Sandstone palette for older or listed buildings (`lb_category` / `height_source`) and neutral elsewhere.
   - Window bands from `storeys_est`.
   - Lit windows at night, following the real sun position.
   - Keep it a single material patch; no per-building textures.
7. **Camera modes.**
   - Orbit (existing).
   - Drone tour along a fixed path of landmarks: George Square, the Clyde, Kelvingrove, the University, the SEC/Hydro.
   - Follow a vehicle (reuse `vehicles.ts`).
   - Time-lapse: a sun-time scrubber, ±12 h.
8. **Performance and fallback.**
   - The mobile/weak-GPU redirect still works.
   - An fps HUD (dev flag).
   - No console errors.
9. **Demo capture.**
   - A script that records a 20–30 s drone-tour clip headlessly, or document manual capture steps if headless WebGL capture is unreliable.
   - Output to `docs/media/` as `.webm` under 8 MB, or link it.

## Gate

- Fallback works; 0 console errors.
